# rusts architecture — how the transpiler works

Same pipeline as `gots` (the Go sister project), retargeted at Rust.

## Pipeline

```
.ts sources
   │
   ▼
collectTs(rootDir)            — recursive .ts walk, skips .d.ts
   │
   ▼
createProgram([src..., ambientTypes(rootDir)], opts)
   │   ambient = rusts/types/*.d.ts  +  <rootDir>/../types/*.d.ts
   │   opts are hardcoded: strictNullChecks ON (null unions must be visible),
   │   strict OFF otherwise, experimentalDecorators, noEmit, skipLibCheck.
   │
   ▼
pass 0 — collectClass() for every class in every file
   │   builds: classFile (name→file), moduleOf (@Module meta),
   │   ctrlOf (@Controller prefix/routes/guards/interceptors),
   │   injectables, fieldsOf/methodsOf (member tables), dtoWithValidate
   │
   ▼
per-file emitFile(sf)
   │   header: "// generated by rusts" + #![allow(...)]
   │   imports → `use` lines (module classes → their new_x factory)
   │   class → emitClass: @Module → factory fn, @Controller/@Injectable/
   │           plain/DTO → struct + impl + new() + trait impls
   │   interface → #[derive] pub struct
   │   fn/enum → direct
   │   main file → pub mod/pub use decls + fn main
   │
   ▼
mod.rs per subdirectory (pub mod + pub use for each file)
```

## Ctx — shared emission state

The `Ctx` struct carries through all emission: the real `checker`/`program`,
`rootDir`, `files`, `nestAlias`, plus:

- `mut`/`guards` — per-body sets from `collectMut`: vars assigned to /
  receivers of `set*`/`push`/`add`/`remove` calls → `let mut`; vars bound to
  `.lock()` results → guard vars (`get`/`set`/`push`/`iterMut` map through
  the MutexGuard deref).
- `renames` — trait impls rename source params (`c` → `ctx`).
- `curRetIsResult`/`curRetFirstIsAny`/`curRetIsVoidResult`/`curRetType` —
  set from the declared return spelling before a body emits, so `return`
  statements know whether `[a, b]` means `Ok`/`Err` or a real tuple.
- `classFile`/`moduleOf`/`ctrlOf`/`injectables`/`fieldsOf`/`dtoWithValidate` —
  pass-0 tables driving decorators and cross-module path resolution.

## Path resolution

`pathForSymbol(ctx, name, file)` is the single choke point:

- same dir → `crate::X` at root, `super::X` in subdirs
- `./sub` → `crate::sub::X` (root) / `super::sub::X` (subdir)
- `../sib` → `crate::sib::X`
- `factoryPath` derives `...::new_x` for `@Module` classes.

`emitType` uses stored `TypeNode`s (not pre-rendered strings) so field
types are emitted only when `curFile` context is known — this was a real
bug (fields got `super::User` instead of `super::dto::User`).

## Emit-time traps (learned the hard way)

- **Flow narrowing lies.** `if (e !== null)` narrows `e` to non-null at the
  use site — `unwrapErr` must read the type at `sym.declarations[0].name`
  (the declaration), not at the reference.
- **`ParamInt` returned `any`** because `import nest from "nest"` errored
  (TS1192 — no default export in the ambient module), cascading `any`s
  through every `Ctx` call. `import * as nest` is required.
- **`strictNullChecks` must be ON** in `createProgram` — `T | null` unions
  collapse without it and every Option/Result decision breaks.
- **`[A, Ptr<Error> | null]` vs `[A, Error | null]`** — the `Ptr<` spelling
  is the escape hatch for real `(A, Option)` tuples; bare `Error [| null]`
  always means `Result`.
- **Sibling mains aren't modules** — a file with top-level statements is its
  own `fn main`; other files in the same dir must NOT be `pub mod`'d into it.
- **Guard receivers** — `.get()`/`.set()` only rewrite for `ctx.guards`
  members; `config.get("KEY")` is a normal method call. Receivers in
  call/prop-access positions go through `emitRef` (guards emit bare names —
  method calls auto-deref; only `get`/`set`/lhs `*` them explicitly).
- **Paren balance in route emission** — the handler string ends `}) }`
  (closure, Arc::new, block); the caller appends the call-closing `)`.
- **`unwrapCast` before null-text checks** — `null!` must text-match `null`
  after stripping NonNullExpression, or `Err` emits `Ok(null!)`.
- **`checks.cjs` mirrors `fail()`** — every unsupported construct must flag
  in `unsupportedDiagnostics()` (95002) AND fail in the emitter, or
  `check` passes while emit breaks.
- **`nestrs/plugin`** is a *copy* — `plugin/checks.cjs` + `index.cjs` are
  self-contained (tsserver can't reach `rusts/src/`). Sync on check changes.

## Framework crate

`nestrs/nest/src/lib.rs` — hand-written. Single-file by design: `Error` +
exception helpers, `Ctx` (param/query/header/status/json/render/body),
`Guard`/`Interceptor`/`WithGuard`/`WithInterceptor`, `Controller` builder
(get/post/patch/delete + `_g` variants), `Deps` (TypeId-keyed Arc store),
`Module`/`App`/`create`/`set_global_prefix`/`set_views`/`listen`, the raw
TCP listener + route matcher (`{param}` segments), `env_or`, and
`Chan<T>`/`chan()` for mpsc channels.
